# 清风聊天 V1.1 修正版

## 这版解决了什么

V1.1 去掉了容易在部分 Node.js 环境安装失败的 SQLite 原生依赖，改成轻量 JSON 数据文件，适合本地测试。

## 启动

1. 安装 Node.js LTS
2. 解压本项目
3. 双击 `start.bat`
4. 浏览器打开 http://localhost:3000

第一次启动会自动安装依赖。

## 注册规则

账号：3-20位字母、数字、下划线
密码：至少6位

数据自动保存到：
- data.json：账号、好友、消息
- uploads：图片

## 测试

注册：
user1 / 123456
user2 / 123456

用两个浏览器窗口登录并添加好友。

## 说明

V1.1 主要用于本地开发测试。公网正式使用前建议改用 PostgreSQL/MySQL、对象存储、HTTPS、密码专用哈希算法、限流、权限验证和备份。
